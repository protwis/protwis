How to use this page

This page shows a 2D t-SNE clustering algorithm embedding of GPCR similarity. Each point is a receptor; nearby points are more similar in the selected dataset.

  • Dataset: switch between Sequence, Inactive structures, and Active structures.
  • Human only: this view contains human receptors only.
  • Structure datasets: include representative structures only (active/inactive sets).
  • Colour by: recolours points by Class/Chemotype/Receptor family/Modality/Sense.
    • {% if not structuresim_scope_class %}
  • Shape by: toggles marker shapes (None/Class), and the shape legend can be used to hide or isolate classes.
    • {% endif %}
  • Click any point to see details in the left-side panel.
  • Legend: click legend items to exclude/include groups in the plot.
